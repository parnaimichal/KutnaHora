KUTNA HORA V OBJEKTIVU – ROZDELENI HTML

index.html
  Kompletní původní web v jednom souboru. Obsahuje společné CSS, JavaScript a vložené fotografie.

komponenty/
  home-page.html    Úvodní stránka
  site-nav.html     Navigace a mobilní menu
  gallery-page.html Galerie
  about-page.html   O projektu
  contact-page.html Kontakt a formulář
  site-footer.html  Patička
  lightbox.html     Zvětšování fotografií

Soubory v komponenty/ jsou samostatné HTML výřezy určené k přehledné editaci a opětovnému vložení do hlavního webu.
Pro zachování kompletní funkčnosti otevři index.html; komponenty samy o sobě neobsahují společné CSS, obrazová data ani aplikační JavaScript.
